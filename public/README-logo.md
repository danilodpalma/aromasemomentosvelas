# Como adicionar o logo da Aromase Momentos

Para adicionar o logo na página inicial:

1. **Crie ou obtenha sua imagem de logo**
   - Formato recomendado: PNG com fundo transparente
   - Dimensões recomendadas: Até 300px de largura
   - Altura será automaticamente ajustada para 120px

2. **Salve a imagem como `logo.png`**
   - Local: `public/logo.png`
   - Certifique-se de que o arquivo está na pasta `public/` do projeto

3. **Características do logo na página:**
   - Altura fixa: 120px
   - Largura automática (mantém proporção)
   - Máximo 300px de largura
   - Efeito hover: leve aumento de escala
   - Clicável: leva para a página inicial

4. **Se não adicionar o logo:**
   - A página funcionará normalmente
   - Aparecerá um espaço vazio onde o logo deveria estar
   - Não haverá erros na aplicação

**Dica:** Use ferramentas como Canva, Figma ou Photoshop para criar um logo profissional com o nome "Aromase Momentos".
